# Merge Criteria

Merge this branch only after reviewers accept that it is a hardening baseline.

Required before merge:

- Production-hardening CI is reviewed.
- Maintainer accepts that remaining proof/auth blockers are documented.
- No README or release text says `production-ready` without qualification.

Required before release:

- Patch set 2 is complete.
- CI passes on release commit.
- Signed receipt sample exists.
- Release checksums are published.
